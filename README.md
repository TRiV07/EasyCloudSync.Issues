# Easy Cloud Sync issues

This public repository is for reporting problems and requesting features for Easy Cloud Sync.

[Open a new issue](https://github.com/TRiV07/EasyCloudSync.Issues/issues/new) or [browse existing reports](https://github.com/TRiV07/EasyCloudSync.Issues/issues) before filing a duplicate.

For a bug report, include the app version, Windows version, steps to reproduce, what you expected, and what happened. For a feature request, describe the problem you want to solve and the workflow you have in mind.

Do not include passwords, access tokens, or private file contents in a public issue.
